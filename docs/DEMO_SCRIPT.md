# Infinite Awareness WebMCP Judge Sandbox - 2:50 Demonstration Script

## 0:00–0:25 - Establish the boundary

“This is a separate, fiction-only judge sandbox. Alex Morgan, all scores and all cohort sessions are invented. There is no login, payment, production API, customer account or persistent database.”

Open the Site tools list and show that exactly eight tools are available. Ask the agent for today’s protocol and the safety boundary. Point to Day 7, **Install - Workspace Expansion**, and the non-treatment statement.

## 0:25–0:50 - Prepare one day

Ask the agent to prepare the fixed three-minute session. The visible page changes to Ready. Explain that the full timer works, but the demonstration can be marked complete for judging without waiting three minutes. Select **Mark demonstration complete**.

## 0:50–1:20 - Turn experience into a review draft

Select **Use fictional sample**, then ask the agent to draft the observation. Show the visible four-part review: observed data, tentative interpretation, uncertainty and next test. Emphasise that drafting does not save anything.

## 1:20–1:50 - Prove the save gate

Ask the agent to save before giving page permission. The call is blocked. Deliberately select **I confirm this fictional draft may be saved**, then ask the agent to save. The call succeeds once and the gate changes to **Save permission consumed**. Ask it to call save again; replay is blocked.

## 1:50–2:20 - Prove blinded scoring

Review the 0–5 usefulness, novelty and testability scores. Ask the agent to record them before permission; the call is blocked. Select the visible score confirmation and retry. The tool records the three scores and explicitly reports that the assignment was not revealed. A replay is blocked.

## 2:20–2:40 - Analyse without overclaiming

Run personal analysis. Show the small fictional history and the caveat that it is descriptive only. Compare with the Global Signal at a minimum sample of 40, then raise the threshold to 49 and show that the 48-session aggregate is suppressed.

## 2:40–2:50 - Reset

Select **Reset fictional demonstration**. The session, draft, confirmations and scores return to the initial fictional state, ready for the next judge.
